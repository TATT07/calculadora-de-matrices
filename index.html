Sistemas aplicados y matemáticos diseñados para validar Jacobi y Gauss-Seidel, mostrando convergencia, física aplicada y reordenamiento de filas.

1. Definición Formal y Descomposición Matricial

Sea un sistema de ecuaciones algebraicas lineales de dimensión $n \times n$ expresado de forma matricial:

A x = b,    donde A ∈ ℝn × n,   x, b ∈ ℝn

Para construir una sucesión iterativa convergente {x(k)}, se realiza una partición de la matriz de coeficientes A. La descomposición aditiva clásica es:

A = D - L - U

donde D es la matriz diagonal principal, -L es la matriz triangular inferior estricta y -U es la matriz triangular superior estricta.

2. Método de Jacobi (Resolución Simultánea)

El método asume que det(D) ≠ 0 y reescribe el sistema como Dx = (L+U)x + b. Su fórmula de recurrencia vectorial y su Matriz de Iteración (TJ) son:

x(k+1) = D-1(L + U)x(k) + D-1b   ⇒   x(k+1) = TJ x(k) + cJ

En forma escalar, las incógnitas se actualizan de manera paralela usando información exclusiva del paso (k):

xi(k+1) = &frac1{aii} · [ bi - ∑j ≠ i aij xj(k) ]

3. Método de Gauss-Seidel (Resolución Sucesiva)

Aprovechando la invertibilidad de la matriz triangular (D - L), evalúa las incógnitas secuencialmente para sustituirlas en tiempo real. Su forma vectorial es:

x(k+1) = (D - L)-1 U x(k) + (D - L)-1b   ⇒   x(k+1) = TGS x(k) + cGS

Escalarmente, el algoritmo incorpora los valores inmediatamente evaluados:

xi(k+1) = &frac1{aii} · [ bi - ∑j < i aij xj(k+1) - ∑j > i aij xj(k) ]

Teorema de Stein-Rosenberg: Establece empíricamente que si A es una matriz con elementos extradiagonales no positivos y diagonal positiva, entonces ρ(TGS) ≤ ρ(TJ) < 1. Si ambos convergen, Gauss-Seidel lo hace estrictamente más rápido.

4. Extensión Numérica: Sobre-Relajación Sucesiva (SOR)

En la computación científica avanzada, Gauss-Seidel se generaliza empleando un factor de relajación escalar ω ∈ (0, 2) para alterar la tasa de convergencia asintótica:

xi(k+1) = (1 - ω) xi(k) + &frac{ω}{aii} · [ bi - ∑j < i aij xj(k+1) - ∑j > i aij xj(k) ]

Nota Topológica: Para ω = 1, la ecuación SOR colapsa exactamente al método de Gauss-Seidel puro.

5. Teoremas de Convergencia y Normas Vectoriales

1. Invertibilidad y Singularidad

El algoritmo colapsa (error por división nula) si existe un autovalor nulo en la diagonal (aii = 0). Computacionalmente se requiere el pivoteo o la permutación estricta de filas antes de iterar.

2. Discos de Gershgorin y Dominancia (EDD)

El teorema de Gershgorin establece que si la matriz es estrictamente dominante por filas (|aii| > ∑ |aij|), los autovalores iterativos quedarán acotados dentro del plano complejo, forzando convergencia incondicional.

3. Análisis del Radio Espectral ρ(T)

La condición necesaria y suficiente para la estabilidad iterativa es que su radio espectral sea menor que 1: ρ(T) = max |λi(T)| < 1. La tasa asintótica está dada por R = -ln(ρ(T)).

4. Evaluación en Norma Infinito (∞)

La tolerancia se valida utilizando la Norma Chebyshev o Norma Máxima || x(k+1) - x(k) ||∞ < ε garantizando que la perturbación se disipe uniformemente en el hiperespacio.

Guía Rápida: Cómo usar la Calculadora

Sigue estos pasos para obtener la solución a tu sistema de ecuaciones lineales sin problemas matemáticos.

Paso 1: Configurar el Sistema

Primero, en el panel lateral izquierdo, define el tamaño de tu matriz (entre 3x3 y 6x6). También puedes cargar uno de los 6 ejemplos prácticos para ver cómo se llenan los datos automáticamente.

  • Iteraciones Mínimas: Forzará al sistema a calcular al menos esta cantidad de iteraciones (6 por defecto).
  • Tolerancia (ε): El programa se detendrá cuando el error sea menor a este valor.
  • Truncamiento vs Redondeo: Escoge si quieres que la calculadora corte los números en el 6to decimal exacto o los redondee (recomendamos redondeo para mayor precisión).

Paso 2: Ingresar la Matriz y Analizar Dominancia

Ingresa los coeficientes de tus ecuaciones. Presta especial atención al recuadro de la parte superior derecha que dice "Analizando...".

¡IMPORTANTE! Uso del botón "Ordenar Filas":

Para que Jacobi y Gauss-Seidel no tiren un error (o den infinito), el número más grande de cada ecuación debe estar en la diagonal principal. Si el sistema te advierte de "Dominancia parcial", dale clic al botón "Ordenar Filas (Dominancia)" y la calculadora permutará automáticamente tus ecuaciones para garantizar la convergencia matemática.

Paso 3: Calcular y Analizar el Desglose

Haz clic en "Calcular Solución Paso a Paso". En la parte inferior aparecerá la solución final obtenida, y justo debajo verás tarjetas expandibles por cada iteración.

  • Haz clic en cualquier encabezado de Iteración para ver su contenido.
  • Ahí verás el despeje de la fórmula para cada variable y la sustitución paso por paso.
  • Usa el botón azul "Ver desglose aritmético" si necesitas ver exactamente cómo se sumó y restó el numerador de manera interna. Esto es muy útil para demostrarle a tu profesor que tus resultados están libres de errores manuales.
